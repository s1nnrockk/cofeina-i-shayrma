# Кофейня и шаурма — сайт

Многостраничный адаптивный сайт для заведения по адресу: Уфа, ул. Дагестанская, 25А.

## Страницы
- `index.html` — главная;
- `menu.html` — меню и информация о наличии;
- `about.html` — о заведении;
- `contacts.html` — адрес, телефон и маршрут;
- `404.html` — собственная страница ошибки;
- `favicon.svg` — значок сайта.

## Просмотр
Откройте `index.html` в браузере.

## Публикация через GitHub Pages
1. Откройте вкладку **Settings** репозитория.
2. В меню слева выберите **Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. В Branch выберите `main`, папку `/(root)`, нажмите **Save**.
5. Дождитесь успешного деплоя в **Actions** и откройте опубликованный адрес, который покажет GitHub.

## Что обязательно подтвердить у владельца до финальной сдачи
- Официальное название и логотип/написание бренда.
- Телефон и адрес (на макете использованы данные, переданные заказчиком).
- Часы работы.
- Полное меню, составы, цены и варианты заказа.
- Реальные фотографии блюд, интерьера и фасада.
- Ссылки на соцсети, доставку и отзывы, если они есть.

**Важно:** цены, конкретные блюда, часы работы, рейтинг и отзывы не выдумывались. В меню пока указаны только общие категории. Фотографии Unsplash — временные демонстрационные изображения; перед передачей заказчику их следует заменить реальными фотографиями заведения или материалами, на использование которых владелец дал согласие.

## Технологии
Чистые HTML, CSS и JavaScript без сборщика и сторонних JS-библиотек. Адаптивная вёрстка, плавная прокрутка, анимации появления блоков, поддержка `prefers-reduced-motion`.
