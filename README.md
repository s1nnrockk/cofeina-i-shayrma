# Кофейня и шаурма — сайт-визитка

Адаптивный одностраничный сайт для заведения на ул. Дагестанской, 25А в Уфе.

## Просмотр
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Перед финальной передачей заказчику подтвердить
- Официальное название заведения и написание бренда.
- Телефон и адрес.
- Актуальные часы работы.
- Полное меню, составы, цены и способы заказа.
- Реальные фотографии заведения и блюд.
- Ссылки на соцсети, доставку и отзывы, если они есть.

На макете намеренно не придуманы цены, конкретные позиции меню, часы работы, рейтинг или обещания о качестве продуктов. Фотографии пока демонстрационные (Unsplash); для финальной версии их лучше заменить материалами владельца.

## Технологии
Чистые HTML, CSS и JavaScript без сборщика и сторонних JS-библиотек. Адаптивная вёрстка, плавная прокрутка, анимация появления блоков с учётом `prefers-reduced-motion`.
